## Cosma Ada Cristina e-Gov 

Dataset-ul ales de mine include descrierea unor cărți de pe aplicația Goodreads.
Deoarece acesta conține 11128 de intrări, am selectat primele 5000 de cărți.

Link: https://www.kaggle.com/datasets/jealousleopard/goodreadsbooks

Proprietăți ale cărților:

- title: string -> titlul cărții
- authors: string -> numele autorilor
- average_rating: double -> rating-ul cărții pe aplicația Goodreads
- isbn: string -> codul unic al cărții în format de 10 cifre
- isbn13: string -> codul unic al cărții în format de 13 cifre
- language_code: string -> codul limbii în care este scrisă cartea
- num_pages: int -> numărul de pagini
- ratings_count: int -> numărul de ratings acordate în aplicația Goodreads
- text_reviews_count: int -> numărul de review-uri scrise în aplicația Goodreads
- publication_date: timestamp -> data la care a fost publicată cartea
- publisher: string -> editura
